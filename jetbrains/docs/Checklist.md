# Checklist

## FloatingCodeToolbar

- As a user, I can view the FloatingCodeToolbar when I select lines.
- As a user, I can click Codex icon in the FloatingCodeToolbar.
- As a user, I can view the line number range in the file reference pasted in all Codex running instances input line after clicking the Codex icon in the FloatingCodeToolbar.

## EditorPopupMenu

- As a user, I can view the EditorPopupMenu when I right-click in the editor.
- As a user, I can click "Send to Codex" in the EditorPopupMenu.
- As a user, I can view the file reference pasted in all Codex running instances input line after clicking "Send to Codex" in the EditorPopupMenu.
- As a user, I can view the line number range in the file reference pasted in all Codex running instances input line after clicking "Send to Codex" in the EditorPopupMenu.
